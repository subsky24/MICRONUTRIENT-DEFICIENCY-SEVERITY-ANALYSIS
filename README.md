# MICRONUTRIENT-DEFICIENCY-SEVERITY-ANALYSIS

🧠 Project Overview

Micronutrient deficiencies remain a silent but widespread public health challenge, particularly in low- and middle-income populations. This project analyzes population-level biomarker data to assess deficiency severity, demographic disparities, and risk drivers across gender, age groups, income levels, geographic latitude, and dietary patterns.

The goal is to move beyond raw deficiency counts and provide actionable health intelligence that supports targeted nutritional interventions and policy decisions.


🎯 Objectives

Quantify micronutrient deficiency burden across the population

Identify high-risk demographic and socioeconomic groups

Evaluate biomarker-specific deficiency severity

Highlight patterns of multiple deficiency burden

Translate findings into clear public health recommendations


Tools & Technologies Used

Power BI – Data modeling, DAX calculations, interactive dashboard design

DAX – Deficiency Severity Index, conditional formatting, KPI logic

Excel / CSV – Data cleaning and preprocessing

Public Health Analytics Concepts – Biomarker interpretation & risk stratification


📂 Dataset Description

Population Size: 4,000 individuals

Key Variables:

Demographics: Gender, Age Group

Socioeconomic: Income Level

Geography: Latitude Region (Low, Mid, High)

Diet Type: Vegan, Vegetarian, Omnivore, Mixed

Biomarkers:

Vitamin D (Serum)

Vitamin B12 (Serum)

Hemoglobin

Folate

Derived Metrics:

Deficiency Severity Index

Deficiency Status

Multiple Deficiency Burden

The dataset captures both biological and social determinants of health, enabling a holistic analysis.
